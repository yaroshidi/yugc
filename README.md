# Elva

A local copy of the [Elva](https://elvalabs.ai/) site, with the opening loader removed. Scroll, the phone scenes, and the linked pages (Press Center, careers, terms, privacy) match the live site.

## Run

```bash
node server.mjs
```

Then open http://localhost:4731

The film is built for a wide desktop window, the same as the original. Set `PORT` if 4731 is taken.
